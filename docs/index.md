# claude-usage-on-icon

**Plan-usage tray icon for Claude Code** - shows your 5-hour and weekly usage in the OS tray or menu bar, without opening the usage page.

## No token, no network

Unlike tools that read your OAuth token and call undocumented APIs, claude-usage-on-icon reads only Claude Code's **official, documented status line input** and a local cache file it writes itself. No HTTP calls. No credentials. No keychains.
